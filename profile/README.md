# DBArtisan - DBA console for schemas you administer

One named console should cover the schemas you administer. Unnamed query windows wait off the live set.

## Session Card

| Slice | What you do in DBArtisan | What remains |
|-------|--------------------------|--------------|
| Arrival | Open DBArtisan on a server you administer and name the DBA desk | A titled SQL console |
| Focus | Keep schema tools on one catalog you own | A short object list |
| Check | Read the statement before you change objects you administer | A confirmed catalog |
| Handoff | Leave the DBArtisan SQL console on that server | A note for the next visit |

## How DBArtisan Sits

DBArtisan does not replace the engine you already run. It sits beside that server as named schema tools and a SQL console for DBArtisan own servers you administer.

## Traffic Light

| Signal | On the DBArtisan DBA desk | What you do |
|--------|---------------------------|-------------|
| Green | Named catalog, one live statement | Continue the same console |
| Amber | Two servers mixed in one window | Split the set before a large change |
| Red | No title, objects from everywhere | Stop and name the DBA desk first |
| Clear | Handoff written, object list short | Close DBArtisan and leave the desk |

## Open Order

1. Open the last DBArtisan session on a server you administer, not a new empty console.
2. Read the schema tools and the last statement.
3. Finish one visible change inside DBArtisan schema tools.
4. Write what changed on objects you own, then close with fewer loose windows than you found.

## Desk Fit

| Who | What DBArtisan holds |
|-----|----------------------|
| DBA desk | Schema tools on servers you administer |
| App owner | SQL console beside the live catalog |
| Shared PC | One DBArtisan profile per person |

## After a Week

A week in DBArtisan is not more connection tabs. It is the same named SQL console, a shorter object list, and a note that still makes sense on Monday. Leave the DBA desk quieter than the session you opened.

## Sign-off

- [ ] The DBArtisan workspace name is short enough to scan
- [ ] Only servers you administer are open
- [ ] A second person can read the last statement
- [ ] The last DBArtisan session still opens after a restart

## Field Note

DBArtisan is easier to trust when the SQL console stays smaller than the export folder around it. Name the DBA desk, keep schema tools on catalogs you administer, finish one statement, and write what changed.
